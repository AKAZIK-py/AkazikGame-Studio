### Key Findings

#### 1. Axial坐标系统正确
```
六边形方向偏移:
- (1, 0)   右
- (1, -1)  右上
- (0, -1)  左上
- (-1, 0)  左
- (-1, 1)  左下
- (0, 1)   右下
```

#### 2. 邻居数量符合预期
| 位置类型 | 邻居数量 | 示例 |
|----------|----------|------|
| 中心位置 | 6 | (4, 1) |
| 边缘位置 | 4 | (0, 1), (4, 0) |
| 角落位置 | 2 | (0, 0), (7, 3) |

#### 3. 坐标转换正确
```
棋盘坐标 → 像素坐标 → 棋盘坐标
完全可逆，精度无损失
小偏移像素正确四舍五入到原格子
```

#### 4. 孤立检测可用于单挂效果
- 检测一个位置周围6格是否有其他角色
- 可实时响应棋盘变化

### Lessons Learned

1. **六边形角落邻居数量不固定**: 取决于具体的坐标偏移方向
2. **坐标转换需要正确的公式**: Pointy-top和Flat-top公式不同
3. **孤立检测是O(1)操作**: 只需检查6个邻居，非常高效
