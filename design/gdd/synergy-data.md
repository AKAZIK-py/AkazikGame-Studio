# 羁绊数据 (Synergy Data)

> **Status**: Designed
> **Author**: user + agents
> **Last Updated**: 2026-03-27
> **Implements Pillar**: 粉丝幻想、策略发现

## Overview

羁绊数据系统定义了游戏中的所有羁绊类型、触发条件和效果参数。羁绊是 V-Tacit 的**核心策略系统**——玩家通过组合特定角色激活羁绊效果，获得属性加成或特殊能力。

羁绊分为以下类型：
- **普通羁绊**: 达到角色数量阈值激活（如 VR 2/4）
- **万能羁绊**: 可计入任意羁绊阈值（狍子）
- **组合羁绊**: 特定角色组合触发强化（EOE姐妹）
- **隐藏羁绊**: 完整版添加（大厂）

**单挂效果**不是羁绊，而是基于棋盘位置的专属效果（hirro）。

羁绊数据是 Foundation 层系统，为羁绊检测和羁绊效果系统提供数据基础。

## Player Fantasy

### 情感目标

羁绊数据系统服务于 **粉丝幻想** 和 **策略发现** 两大支柱：

1. **真实羁绊**: 羁绊基于真实虚拟主播团体（VR、糖、EOE姐妹等），让粉丝看到"他们真的在一起"
2. **策略深度**: 不同羁绊组合创造不同的游戏体验，玩家探索"最强配队"
3. **惊喜发现**: 万能羁绊（狍子）和组合羁绊（EOE姐妹）提供意外惊喜

### 参考游戏

- **云顶之弈**: 羁绊系统原型，阈值式激活
- **金铲铲之战**: 简化的羁绊体验，适合轻度玩家

### MVP范围

- MVP阶段: 10个基础羁绊定义、阈值和效果参数
- MVP+阶段: 羁绊激活对话、特效
- 完整版: 隐藏羁绊、羁绊皮肤

## Detailed Design

### Core Rules

#### 羁绊数据结构

每个羁绊由以下字段定义：

| 字段 | 类型 | 描述 |
|------|------|------|
| `id` | string | 羁绊唯一标识 |
| `display_name` | string | 显示名称 |
| `type` | enum | 羁绊类型 |
| `thresholds` | array | 触发阈值和对应效果 |
| `effect_ids` | array | 效果ID列表（指向羁绊效果系统） |

#### 羁绊类型枚举

| 值 | 描述 | 示例 |
|---|---|---|
| `normal` | 普通羁绊，达到角色数量阈值激活 | VR, 偶像 |
| `wildcard` | 万能羁绊，可计入任意羁绊 | 狍子 |
| `combo` | 组合羁绊，特定角色组合触发 | EOE姐妹 |
| `hidden` | 隐藏羁绊，暂不激活 | 大厂 |

#### 初始羁绊列表

| 羁绊 | 类型 | 角色 | 阈值 | 效果方向 |
|------|------|------|------|----------|
| VR | normal | 小可, 阿梓, 七海, 恬豆 | 2/4 | 攻击力加成 |
| 偶像 | normal | 雫lulu, 恬豆, 永雏塔菲, 星瞳, 七海 | 2/4/5 | 生命值加成 |
| 歌手 | normal | 小可, 泽音, 露早, 柚恩, 阿梓 | 2/4 | 技能伤害加成 |
| 糖 | normal | 雪糕, 白神遥, 阿梓, 永雏塔菲 | 2/3 | 攻速加成 |
| 枪手 | normal | 雪糕, hirro | 2 | 普攻触发额外射击 |
| PSP | normal | 东爱璃, 白神遥 | 2 | 全体增益 |
| EOE姐妹 | combo | 露早, 柚恩 | 2 | 组合强化，达到3费数值（攻击×1.8，生命×1.5）|
| 狍子 | wildcard | 东爱璃 | 1 | 可计入任意羁绊 |
| 东京 | normal | 雫lulu | 1 | 单体效果 |
| 大厂 | hidden | 星瞳 | — | 暂不激活 |

#### 特殊效果（非羁绊）

| 效果 | 触发条件 | 受益角色 | 效果 |
|------|----------|----------|------|
| 单挂效果 | 棋子周围6格无其他棋子 | hirro | 数值加成 |

#### 万能羁绊规则

狍子（东爱璃）可以计入任意羁绊的阈值：
- 示例：场上已有阿梓(VR)、小可(VR)，再加东爱璃(狍子)，可触发 VR(3)
- 狍子本身不提供独立效果，只作为"万能凑数"
- 一个狍子只能计入一个羁绊（玩家优先级决定）

### States and Transitions

羁绊数据是**静态只读数据**，本身没有状态转换。

#### 羁绊激活状态

虽然羁绊数据是静态的，但羁绊检测系统会追踪每个羁绊的激活状态：

```
[未激活] ──角色数量达标──> [激活]
    ↑                       │
    └──角色数量下降──────────┘
```

#### 羁绊层级状态

对于多阈值羁绊（如 VR 2/4）：

```
[未激活] ──2个角色──> [1级激活] ──4个角色──> [2级激活]
    ↑                    │                      │
    └────────────────────┴──────────────────────┘
                     角色数量下降
```

#### 数据加载流程

```
游戏启动 → 加载所有羁绊数据 → 缓存在 SynergyRegistry → 供羁绊检测系统查询
```

### Interactions with Other Systems

羁绊数据是 Foundation 层系统，被以下系统依赖：

| 系统 | 依赖类型 | 使用内容 |
|------|----------|----------|
| **羁绊检测** | 强依赖 | 读取 `thresholds` 判断是否激活 |
| **羁绊效果** | 强依赖 | 读取 `effect_ids` 查询具体效果 |
| **UI系统** | 弱依赖 | 读取 `display_name` 显示羁绊名称 |

#### 接口定义

```gdscript
# SynergyRegistry.gd - 羁绊数据注册表（单例）
class_name SynergyRegistry

## 初始化：加载所有羁绊数据
func initialize() -> void

## 获取单个羁绊数据
func get_synergy(id: String) -> SynergyData

## 获取所有羁绊
func get_all_synergies() -> Array[SynergyData]

## 按类型筛选
func get_by_type(type: String) -> Array[SynergyData]

## 获取羁绊阈值
func get_thresholds(synergy_id: String) -> Array[int]
```

## Formulas

羁绊数据系统定义阈值，具体效果数值由羁绊效果系统实现。

### 阈值设计原则

| 羁绊角色数 | 建议阈值 | 原因 |
|------------|----------|------|
| 2人 | 2 | 单一阈值，必须凑齐 |
| 3人 | 2/3 | 两档，灵活配置 |
| 4人 | 2/4 | 两档，覆盖常见组合 |
| 5人+ | 2/4/5+ | 三档，满足不同规模 |

### 效果强度递增

```
1级效果 (最低阈值) = 基础值
2级效果 (中等阈值) = 基础值 × 1.8
3级效果 (最高阈值) = 基础值 × 3.0
```

## Edge Cases

### 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 羁绊ID不存在 | 返回 `null`，调用方处理 |
| 阈值为空 | 数据验证时报错 |
| effect_id 指向不存在的效果 | 运行时警告，羁绊激活但无效果 |
| 角色有隐藏羁绊标签 | 正常加载，但不参与检测（隐藏羁绊暂不激活） |

### 万能羁绊边界

| 情况 | 处理方式 |
|------|----------|
| 多个羁绊同时需要狍子凑数 | 玩家优先级决定计入哪个 |
| 场上没有其他羁绊 | 狍子不提供独立效果 |
| 狍子被移出棋盘 | 所有依赖它的羁绊重新计算 |

### 组合羁绊边界

| 情况 | 处理方式 |
|------|----------|
| EOE姐妹只上一个 | 羁绊未激活 |
| 露早或柚恩被移出 | 羁绊效果消失 |

## Dependencies

### 上游依赖

**无**。羁绊数据是 Foundation 层系统。

### 下游依赖

| 系统 | 依赖类型 | 使用内容 |
|------|----------|----------|
| **羁绊检测** | 强依赖 | 读取 `thresholds` 判断激活条件 |
| **羁绊效果** | 强依赖 | 读取 `effect_ids` 查询效果 |
| **UI系统** | 弱依赖 | 读取 `display_name` 显示 |

### 与角色数据的关联

羁绊数据与角色数据通过 **标签** 关联：
- 角色数据的 `synergy_tags` 字段包含羁绊标签ID
- 羁绊数据的 `id` 与标签ID对应
- 这是一种 **松耦合** 关联，便于扩展

## Tuning Knobs

### 阈值调整

| 参数 | 安全范围 | 过高风险 | 过低风险 |
|------|----------|----------|----------|
| VR 阈值 | 2/3, 2/4 | 4人太难得 | 2人太容易 |
| 偶像 阈值 | 2/4/5 | 5人难以达成 | 2人太容易 |
| 糖 阈值 | 2/3 | 3人太难得 | 无影响 |

### 效果强度

效果强度由羁绊效果系统定义，羁绊数据只提供阈值参考：
- 阈值越高，效果应该越强
- 同一羁绊的不同层级效果应该有明显差距
