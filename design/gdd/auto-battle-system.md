# 自走战斗系统 (Auto-Battle System)

> **Status**: Draft
> **Author**: game-designer agent
> **Last Updated**: 2026-04-02
> **Implements Pillar**: 策略发现

## Overview

自走战斗系统是战斗系统的扩展，让棋盘上的棋子能够**自动移动、攻击、释放技能**。玩家点击"开始战斗"后，可以看到完整的战斗过程，而非仅显示数值结果。

MVP+阶段的核心目标是"让棋子动起来"，让玩家直观理解战斗是如何进行的，增强策略反馈的沉浸感。

## Player Fantasy

### 情感目标

1. **视觉验证**: 玩家不再只看到"55%胜率"，而是看到自己的棋子如何移动、攻击、被击败
2. **策略理解**: 通过观察战斗过程，玩家能理解"为什么输了"——是站位问题？还是羁绊效果不够？
3. **戏剧性时刻**: 关键一击、逆转翻盘、最后一搏——这些瞬间让战斗更有记忆点

### 参考游戏

- **云顶之弈**: 自走战斗的标杆，棋子自动寻路、攻击、释放技能
- **战斗竞技场**: 简化的自走战斗，强调策略而非操作

### MVP+范围

- 回合制战斗（非实时）
- 棋子移动和攻击动画
- 战斗日志显示
- 加速/跳过功能

### 回合制规则

**行动顺序**:
1. 每回合开始时，根据速度属性对所有棋子排序
2. 速度高的棋子先行动
3. 每个棋子行动一次后，进入下一回合
4. 重复直到一方全部阵亡

**行动内容**:
每个棋子的一个回合包含：
1. **技能检查**: 如果技能可用，优先释放技能
2. **攻击检查**: 如果攻击范围内有敌人，执行攻击
3. **移动决策**: 如果无法攻击，移动向最近的敌人
4. **等待**: 如果无有效行动，等待下一回合

### 移动规则

**六边形棋盘移动**:
- 每回合最多移动 1 格
- 只能移动到相邻的6个格子（六边形邻居）
- 不能穿过敌方棋子
- 可以穿过友方棋子（交换位置）
- 不能移动到已占据的格子

**移动AI**:
```
1. 寻找最近的敌方目标
2. 计算到达目标的路径（A*简化版）
3. 向目标方向移动一格
4. 如果目标已在攻击范围内，不移动
```

### 攻击规则

**攻击范围**:
| 定位 | 攻击范围 | 说明 |
|------|----------|------|
| output | 1格 | 近战输出 |
| tank | 1格 | 近战坦克 |
| warrior | 1格 | 近战战士 |
| core | 1-2格 | 中程核心 |
| support | 2格 | 远程辅助 |
| mage | 2-3格 | 远程法师 |

**攻击流程**:
1. 检查攻击范围内是否有敌人
2. 选择目标（优先级：最低血量 > 最近距离）
3. 造成伤害 = 攻击力 × 技能系数（默认1.0）
4. 播放攻击动画
5. 显示伤害数字
6. 如果目标生命值 ≤ 0，目标阵亡

### 技能规则（简化版）

MVP+阶段，技能采用简化触发：
- **被动技能**: 战斗开始时自动应用（由羁绊效果系统处理）
- **主动技能**: 按照触发器条件自动触发（由AI系统判断）

技能触发优先级：
1. 触发条件满足 → 释放技能
2. 无技能或条件不满足 → 普通攻击

### 胜负判定

**胜利条件**: 敌方全部阵亡
**失败条件**: 我方全部阵亡
**平局条件**: 超过最大回合数（50回合），双方均有存活

## Formulas

### 速度计算

```
速度 = 基础速度 + 羁绊加成

基础速度 = 10  # 所有角色相同
羁绊加成 = 激活羁绊数 × 2  # 每激活一个羁绊+2速度
```

**速度范围**: 10-20（无羁绊到全羁绊）

### 伤害计算

```
伤害 = 攻击力 × 技能系数 × 暴击系数

攻击力 = 角色最终攻击力（来自属性计算系统）
技能系数 = 1.0（默认）或技能定义值
暴击系数 = 1.0（MVP+暂不支持暴击）
```

### 行动顺序排序

```
行动顺序 = 按速度降序排列
速度相同时，随机排序
```

### 战斗时长估算

```
最大回合数 = 50
平均每回合棋子数 = 6（双方各3）
总行动次数 = 50 × 6 = 300次
动画时长 = 0.5秒/行动
总战斗时长 ≈ 150秒（1x速度）
```

**加速建议**:
- 1x: 完整动画
- 2x: 动画加速2倍
- 4x: 动画加速4倍
- 跳过: 直接显示结果

## Edge Cases

### 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 棋盘上无我方棋子 | 提示"请先放置角色"，不进入战斗 |
| 棋盘上无敌方棋子 | 自动胜利（不应发生） |
| 棋子无法移动（被包围） | 跳过移动，直接攻击或等待 |
| 棋子无攻击目标 | 移动向最近敌人或等待 |
| 战斗超过50回合 | 判定平局，显示双方剩余棋子 |
| 伤害为0或负数 | 最小伤害为1 |
| 棋子生命值异常（<0） | 设为0，触发阵亡 |

### 动画异常

| 情况 | 处理方式 |
|------|----------|
| 动画播放卡顿 | 跳过当前动画，继续战斗流程 |
| 多个动画同时触发 | 按队列顺序播放 |
| 棋子移动到无效位置 | 取消移动，原地等待 |

### 数据异常

| 情况 | 处理方式 |
|------|----------|
| 角色属性缺失 | 使用默认值（攻击50，生命600） |
| 技能定义无效 | 跳过技能，使用普通攻击 |
| 羁绊效果未应用 | 使用基础属性继续战斗 |

## Tuning Knobs

### 战斗参数

| 参数 | 默认值 | 安全范围 | 说明 |
|------|--------|----------|------|
| 最大回合数 | 50 | 30-100 | 防止无限战斗 |
| 基础速度 | 10 | 5-20 | 所有角色基础速度 |
| 羁绊速度加成 | 2 | 1-5 | 每激活羁绊增加速度 |
| 默认动画时长 | 0.5秒 | 0.2-1.0秒 | 单个行动动画 |

### 攻击范围

| 参数 | 默认值 | 安全范围 | 说明 |
|------|--------|----------|------|
| 近战范围 | 1格 | 1-2格 | output/tank/warrior |
| 中程范围 | 1-2格 | 1-3格 | core |
| 远程范围 | 2-3格 | 2-4格 | support/mage |

### AI参数

| 参数 | 默认值 | 安全范围 | 说明 |
|------|--------|----------|------|
| 目标选择优先级 | 血量最低 | 血量/距离/随机 | AI选择目标的策略 |
| 移动策略 | 向最近敌人 | 最近/最优位置 | AI移动决策 |

### 调参建议

1. **战斗节奏**: 如果战斗太慢，减少动画时长或增加加速倍率
2. **AI强度**: 如果AI太弱，优化目标选择算法
3. **视觉反馈**: 如果伤害数字太小，增加字体大小或颜色对比
