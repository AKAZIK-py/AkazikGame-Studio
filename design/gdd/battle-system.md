# 战斗系统 (Battle System)

> **Status**: Approved
> **Author**: user + agents
> **Last Updated**: 2026-03-28
> **Implements Pillar**: 策略发现

## Overview

战斗系统负责**计算双方阵容的胜率**。MVP阶段采用纯数值计算，无实时战斗动画。玩家组建好阵容后，点击"开始战斗"，系统计算玩家阵容与AI敌方阵容的战力对比，输出胜率和战斗结果。

本系统是验证玩家策略的核心——羁绊组合是否有效、阵容搭配是否合理，都通过战斗结果来反馈。

## Player Fantasy

### 情感目标

战斗系统服务于 **策略发现** 支柱：

1. **验证策略**: 玩家尝试不同的羁绊组合，通过战斗结果验证"这个配队强不强"
2. **清晰反馈**: 胜率百分比让玩家直观理解阵容强度，而非模糊的"赢了/输了"
3. **快速迭代**: 无动画战斗让玩家能快速尝试多种组合，找到最强配队

### 参考游戏

- **云顶之弈**: 战斗验证羁绊组合效果，但战斗时间较长
- **自走棋类手游**: 简化战斗流程，强调策略而非操作

### MVP范围

- MVP阶段: 纯数值计算，秒出结果，显示胜率百分比
- MVP+阶段: 战斗日志（显示每次攻击/技能触发）
- 完整版: 战斗动画、战斗回放

## Detailed Design

### Core Rules

```gdscript
# BattleSystem.gd
class_name BattleSystem

## 计算胜率
func calculate_win_rate(player_team: Array, enemy_team: Array) -> float

## 执行战斗计算
func execute_battle() -> Dictionary
```

### 战斗流程

```
[准备阶段]
玩家放置角色 → 触发羁绊检测 → 应用羁绊效果 → 计算最终属性

[战斗阶段]
点击"开始战斗" → 计算双方战力 → 计算胜率 → 判定胜负 → 存储结果

[结果阶段]
显示胜率百分比 → 显示战斗结果 → 提供重置选项
```

### AI敌方阵容

MVP阶段，敌方由系统从预设阵容池中随机选择：

**预设阵容池**（初期设计）:

| 编号 | 阵容名称 | 角色组成 | 总战力 | 难度 |
|------|----------|----------|--------|------|
| 1 | 歌手队 | 小可, 泽音, 露早, 柚恩 | ~2800 | 简单 |
| 2 | VR基础 | 小可, 阿梓, 七海 | ~3200 | 中等 |
| 3 | 糖分小队 | 雪糕, 白神遥, 永雏塔菲 | ~3000 | 中等 |
| 4 | 偶像阵 | 雫lulu, 恬豆, 七海 | ~3500 | 困难 |
| 5 | 随机组 | 3-4个随机角色 | 2500-4000 | 可变 |

**敌方生成规则**:
- 从预设池中随机选择一个阵容
- 敌方角色同样应用羁绊效果（如有）
- 后续版本可支持难度递增机制

### 胜率计算公式

```
队伍战力 = Σ(角色战力)

角色战力 = 攻击力 × 生命值 × 羁绊系数 × 定位系数

玩家胜率 = 玩家战力 / (玩家战力 + 敌方战力)
```

> **注意**: MVP阶段暂不包含技能系数，所有角色技能系数默认为1.0。

## Formulas

### 战力计算公式

**单个角色战力**:
```
角色战力 = 攻击力 × 生命值 × 羁绊系数 × 定位系数
```

> **MVP简化**: 暂不包含技能系数。技能系数预留给MVP+版本，用于差异化角色技能强度。

**变量定义**:

| 变量 | 描述 | 取值范围 | 来源 |
|------|------|----------|------|
| `攻击力` | 角色最终攻击力 | 30-150 | 属性计算系统 |
| `生命值` | 角色最终生命值 | 400-1500 | 属性计算系统 |
| `羁绊系数` | 羁绊效果带来的乘数 | 1.0-2.0 | 羁绊效果系统 |
| `定位系数` | 定位带来的修正 | 0.8-1.2 | 角色数据 |

**定位系数参考值**:

| 定位 | 系数 | 原因 |
|------|------|------|
| output | 1.1 | 高输出但脆弱，战力偏向攻击 |
| tank | 1.0 | 标准战力 |
| support | 0.9 | 辅助效果不直接体现在战力中 |
| core | 1.2 | 综合能力强 |
| warrior | 1.0 | 标准战力 |
| mage | 1.05 | 技能伤害有延迟 |

### 胜率公式详解

```
玩家胜率 = floor(玩家战力 / (玩家战力 + 敌方战力) × 100) / 100
```

**示例计算**:
- 玩家战力: 3500
- 敌方战力: 2800
- 胜率 = 3500 / (3500 + 2800) = 3500 / 6300 ≈ 0.556 ≈ **55.6%**

### 胜负判定

```
最终判定 = random(0, 1) < 玩家胜率 ? 胜利 : 失败
```

胜率表示概率，不是绝对结果：
- 70%胜率 ≠ 必胜
- 30%胜率 ≠ 必败
- 多次战斗结果会趋向胜率分布

## Edge Cases

### 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 玩家阵容为空 | 提示"请先放置角色"，不执行战斗 |
| 敌方阵容为空 | 视为自动胜利（不应发生，日志警告） |
| 战力为0 | 视为必然失败（配置错误，日志警告） |
| 胜率计算为NaN/Infinity | 返回50%胜率，日志错误 |
| 羁绊系数叠加超过上限 | 限制单个角色最大羁绊系数为2.5 |
| 同一角色多个实例 | 各自独立计算战力，可叠加 |

### 数值溢出保护

- 战力计算中间值使用浮点数
- 最终战力取整到整数
- 胜率四舍五入到小数点后一位

### 战斗异常处理

| 异常 | 处理 |
|------|------|
| 计算超时（>100ms） | 使用简化公式，记录警告 |
| 属性数据缺失 | 使用默认值（攻击50，生命600），记录警告 |
| 羁绊效果未加载 | 使用1.0系数，记录警告 |

## Tuning Knobs

### 战力计算参数

| 参数 | 默认值 | 安全范围 | 说明 |
|------|--------|----------|------|
| 定位系数.output | 1.1 | 1.0-1.3 | 输出角色战力修正 |
| 定位系数.tank | 1.0 | 0.9-1.1 | 坦克角色战力修正 |
| 定位系数.support | 0.9 | 0.8-1.0 | 辅助角色战力修正 |
| 定位系数.core | 1.2 | 1.0-1.3 | 核心角色战力修正 |
| 最大羁绊系数 | 2.5 | 2.0-3.0 | 防止羁绊叠加过强 |

### AI难度参数

| 参数 | 默认值 | 安全范围 | 说明 |
|------|--------|----------|------|
| 阵容池大小 | 5 | 3-10 | 预设阵容数量 |
| 随机阵容概率 | 20% | 0-50% | 使用随机阵容的概率 |
| 最低敌方战力 | 2000 | 1500-3000 | 防止敌方太弱 |
| 最高敌方战力 | 4500 | 3500-6000 | 防止敌方太强 |

### 调参建议

1. **初期**: 使用较低的敌方战力（2000-3000），让玩家体验胜利
2. **中期**: 根据玩家胜率分布调整难度
3. **后期**: 可添加难度选择（简单/普通/困难）

## Acceptance Criteria

### 功能完整性

- [ ] 玩家点击"开始战斗"后正确计算胜率
- [ ] 战斗结果（胜/负）正确判定并显示
- [ ] 战斗结果存储到游戏状态系统

### 数值正确性

- [ ] 战力计算公式与设计一致
- [ ] 胜率计算结果在0%-100%之间
- [ ] 羁绊系数正确应用到战力计算

### AI敌方

- [ ] AI敌方阵容从预设池中正确选取
- [ ] AI敌方同样应用羁绊效果（如有）
- [ ] 随机阵容生成符合概率分布

### 边界处理

- [ ] 空阵容提示正确
- [ ] 异常值不会导致崩溃
- [ ] 日志正确记录异常情况

### 性能要求

- [ ] 战斗计算完成时间 < 100ms
- [ ] 结果显示无延迟感
