# 纸境 INKBOUND

中文第一人称波次挑战。蓝墨线稿、横线纸、几何描边与排线着色，无现实纹理。玩法采用非写实墨团清除：速写笔（连续）、橡皮泵（扩散）、针管笔（精确）、折纸尺（近距）。

## 一分钟本地启动

在仓库里玩：让 agent 执行 [`HANDOFF.md`](HANDOFF.md)。固定 `http://127.0.0.1:8787`，health 通过才算开着。

手动启动需要 Node.js 20 或更高版本。在本目录运行：

```sh
npm install
HOST=127.0.0.1 PORT=8787 npm start
```

确认 `curl -fsS http://127.0.0.1:8787/health` 返回 `"ok":true` 后再打开该地址。单人模式不依赖 WebSocket；客户端 public/ 也能部署到任何静态网页服务器。玩完用 Ctrl+C 或 HANDOFF 的停止步骤结束进程。

本地联机：分别打开两个浏览器窗口，点击“和朋友同页”，地址填 `ws://127.0.0.1:8787`，输入相同的 6–12 位房间码，即可进入同一个 2–4 人协作房间。

## 目录

- `public/`：完整可部署客户端，Three.js 依赖已本地化。
- `server.mjs`：真实 WebSocket 服务。房间隔离，最多 4 人，60Hz 模拟、约 20Hz 状态广播。
- `core.mjs`：权威模拟。与 public/core.mjs 规则一致。
- `package.json`：固定 ws 依赖和启动命令。
- `THIRD-PARTY-LICENSES/`：依赖许可证。

## 公网联机部署

静态网页上线不等于多人服务已上线。发布网页没有预置 WSS 服务地址；务必独立部署服务并启用 TLS。

Linux 示例：

```sh
HOST=0.0.0.0 PORT=8787 ALLOWED_ORIGINS=https://你的游戏页面来源 npm start
```

- 使用 nginx 或支持 WebSocket Upgrade 的网关终止 TLS，公开 `wss://你的联机域名`。
- `ALLOWED_ORIGINS` 必须填网页实际执行时的 Origin（协议+域名+端口），不要填含 /apps/ 路径的完整 URL；多个来源用英文逗号分隔。可在浏览器控制台查看 `location.origin`。
- 默认只监听 127.0.0.1；容器部署需明确设置 HOST=0.0.0.0。
- HTTPS 游戏页面拒绝 ws:// 地址，必须使用 wss://。
- 可以用 `/health` 检查服务健康。
- 不需要把任何私钥、服务器凭据或身份令牌放入客户端。

## 操作

WASD 移动；鼠标转向；左键点绘；右键精确观察；Shift 快走；R 补充墨水；1–4 或滚轮换文具；P / Esc 暂停。鼠标锁定受限时可按住右键拖动转向。

手机有虚拟摇杆、右侧滑动转向、点绘和 R 按钮。完整体验优先桌面 Chrome / Edge。

清空一波后休息 6 秒，纸面恢复 18 点并补满文具。联机菜单不会暂停房间，纸面耗尽的玩家可以等待队友清完此波后恢复。

## 渲染与兼容

- 首选 Three.js WebGL2 + 自定义 GLSL 排线材质 + 几何双描边。
- 无 WebGL2 时，兼容模式使用相同 Three.js 场景、相机与模型做 Canvas2D 三维投影，不替换游戏规则。
- 未引入照片、现实材质或外部图片服务；音效由 Web Audio 合成，用户操作后才启动。
- 游戏最高分和偏好保存在本机 localStorage，不上传。

## 证据与限制

已通过：23 项核心规则测试、10 项真实 WebSocket 协议测试、18 项浏览器端到端测试；三屏首页和局内截图审阅。测试覆盖 WebGL2 软件渲染、GPU 禁用兼容、双浏览器同房、碰撞、射线遮挡、四类文具、补充、暂停、手机输入。

不代表已完成：公网跨网络连接验证、多人长时间压力测试、所有显卡/手机真机性能验收、真人主观手感评测。当前联机适合朋友间测试，不是正式竞技基础设施。

安全边界：服务器不信任客户端坐标、得分和墨水；校验输入范围，限制消息大小、消息频率、房间容量；心跳清理、输入超时停止。房间码属于轻量共享凭据，不是账号身份鉴权。正式运营还需要账户、匹配、监控、反作弊与容量规划。
